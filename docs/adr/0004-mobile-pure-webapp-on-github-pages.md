# 移动端为独立纯前端写回应用，托管于 GitHub Pages

状态：2026-09-30 起移出本项目（见 ADR 0006），移动端由新的同步仓库实现。

手机端定位从只读应急升级为可编辑写回：一个部署在 GitHub Pages 的静态页面，在浏览器内完成拉取密文（坚果云 WebDAV）、scrypt-WASM 派生解密、编辑与写回，没有自建后端。曾考虑局域网访问家用电脑（出门即失效）、只读页（不满足高频修改场景）、Qoder Sites 托管（多一个平台依赖）。代码仓与数据仓严格分离，页面公开不构成泄露面。

## 后果

- WebCrypto 不支持 scrypt，须引入 WASM 实现（如 hash-wasm），N=131072 派生预计 1–5 秒。
- 浏览器直连坚果云 WebDAV 的 CORS 行为未验证，是本项目最大外部风险；若 PUT 被跨域策略阻断，手机端降级为只读并回到 ADR 0002 的备选重新评估，而非搭建中转服务（那会重新引入服务端信任面）。
- 页面代码存放于独立私有仓库构建后发布（与现公开仓库 Password-Vault 隔离），防止同步脚本或配置误入公网仓库。
