# 项目范围收敛为纯本地保存，多设备同步移交独立仓库

2026-09-30 决定：本仓库只做单机本地保存——数据在磁盘 `vault.pvlt`、服务只监听 `127.0.0.1`、跨设备靠导出加密备份再导入。多设备同步（含手机端）另开新仓库专门做，本仓库不再承接其工单。已完成的同步铺垫（`SyncProvider` 接缝、`shared/merge.ts` 三方合流纯函数及其测试）在本仓库属于无入口的死代码，去留单独决定；ADR 0002 / 0003 / 0004 与 `docs/specs/2026-09-29-多设备同步.md` 保留为决策历史，由新仓库按需承接。

## 后果

- ADR 0002（云端只存密文、无自建服务端）、0003（合流字段进加密载荷、信封保持 version 1）、0004（移动端纯前端托管 GitHub Pages）对本仓库**不再是待实现约束**，只是历史记录；新仓库若沿用同一信任模型，应把这三条连同 `同步副本 / 基准版本 / 条目级合流 / 解锁基线 / 移动端` 五个术语一起搬过去，本仓库术语表不再收录它们。
- README 的"无跨设备同步；换机器需手动迁移存储目录或导入备份"从**已知限制**变成本项目的**边界声明**：它不是待补的缺口，是设计意图。
- 分发（ADR 0005 的绿色包）只服务单机场景；任何"多设备"诉求一律指向新仓库，不在本仓库加同步半成品。
